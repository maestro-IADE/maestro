# 용어

## 요약

같은 것을 서너 가지 말로 부르던 것(프로젝트/저장소, 워크트리/에이전트 블록/워커, Lead/지휘자/조율자, Chat·CLI/채팅·터미널)을 한 이름으로 정한 표예요. 화면 글(버튼, 라벨, 툴팁, 상태, 확인 창)은 아래 "쓰는 말"만 써요. UI 구조 재구성의 단계 11(용어 마감)과 12(채팅/터미널)에서 화면 글을 모두 이 표대로 고쳤어요.

**문구 규칙**(`maestro-web/DESIGN.md` "문구")
- 버튼·라벨·툴팁·한 문장짜리 안내 끝에 마침표·느낌표를 붙이지 않아요. 여러 문장인 문단만 마침표를 써요.
- 버튼은 동작 이름이에요("폐기", "목록에서 제거"). "확인"처럼 무엇을 하는지 말하지 않는 이름은 쓰지 않아요.
- 툴팁은 "이름 (단축키)" 또는 "이름 · 짧은 설명"이에요. 상태 글은 짧게 써요.

## 구현

- 상태 이름: `statusText`(src/status.tsx)가 글리프의 툴팁·이름과 워커 카드의 상태 글자를 같이 줘요.
- 권한 모드: `PERMISSION_NAMES`(src/agents.tsx)가 다섯 모드의 이름·짧은 이름·설명을 이 표 그대로 가져요(`permissionOf(id)`, 모든 모드는 `PERMISSIONS`). 고르는 곳(새 에이전트 창, 에이전트 설정 창, 설정 → 에이전트의 기본 권한)은 `permissionsFor(id)`로 그 에이전트가 받는 모드만 보여요(카탈로그 `permission_modes`, catalog.rs). 그래서 Antigravity에는 "매번 묻기"가 없어요.
- 확인 창의 제목·버튼 글: 호출하는 곳마다 `ask({ title, confirm })`로 줘요. → [메뉴와 확인 창](menus-and-dialogs.md)

## 제약과 알려진 문제

- 화면 글(src)에서 "쓰지 않는 말"은 모두 뺐어요: 단계 11이 대부분, 단계 12가 채팅/터미널 쪽 말(`"Chat"`, `CLI 보기`, `CLI에서`, "CLI로 전환")을 뺐어요(`rg "\"Chat\"|CLI 보기|CLI에서" src` 0줄). 슬래시 메뉴의 메모("터미널에서 열려요", "채팅에서는 안 돼요 · 터미널에서")도 바꿨어요.
- 백엔드(Rust)의 오류 문구는 이 표의 범위 밖이에요. 그래서 채팅에서 `!`나 안 되는 명령을 보낼 때의 오류, 로그인 필요 같은 글에는 아직 "CLI 보기에서"가 나와요.

## 결정 기록

- 2026-11-14: 지휘하는 에이전트의 이름을 "마에스트로"에서 "Lead"로 바꿨어요. 앱 이름(Maestro)과 블록 이름이 같아 무엇을 가리키는지 헷갈렸어요. 영어 이름으로 하기로 하고, Master는 Git의 `master` 브랜치와 겹치고 master/slave를 떠올리게 해서, Conductor는 같은 분야에 같은 이름의 제품이 있어서 뺐어요. 화면 글, 문서, 기본 플레이북, 에이전트에게 주는 시작 지시문을 모두 바꿨어요. 코드 안 이름(`isMaestro`, `role: "maestro"`, `create_maestro`)과 `maestro` CLI는 그대로예요. 이 에이전트의 이름은 고정이라 예전에 "Maestro"로 저장된 것도 화면과 `maestro --to`에서는 "Lead"로 보여요(`--to maestro`도 받아요).
- 2026-11-13 (리뷰 수정): 남은 "저장소"와 문장 속 "Maestro"를 뺐어요. 로딩 글 "저장소와 워크트리를 읽는 중…"(메인 창, 분리 창 탭 묶음) → "프로젝트와 에이전트를 읽는 중…", 토스트 "워크트리를 읽지 못한 저장소가 있어요" → "에이전트를 읽지 못한 프로젝트가 있어요", 폐기 확인·에이전트 붙이기·외부 배지의 "Maestro 밖에서 만든 워크트리" → "앱 밖에서 만든 워크트리", 설정 → 정보 설명 "설치된 Maestro의 버전…" → "설치된 앱의 버전…". 폐기 창의 버리기 줄은 두 문장 사이에 마침표가 빠져 있어 넣었어요. 시스템 탭 이름 "Maestro 문서와 플레이북"은 기능 이름(Maestro 문서)이라 그대로 뒀어요.
- 2026-11-13 (UI 구조 재구성 단계 12): 채팅/터미널 말을 마감했어요. 헤더 세그먼트 "Chat | CLI"는 아이콘 하나("이 에이전트만 터미널로 보기" / "채팅으로 돌아가기")가 됐고, "CLI에서 보기" → "터미널에서 보기", "CLI 보기에서" → "터미널에서", 터미널 위 띠 "CLI로 전환" → "터미널로 넘기기"예요. 슬래시 메뉴 메모는 백엔드가 만들지만 오류가 아니라 화면 라벨이라 같이 바꿨어요.

- 2026-11-13 (UI 구조 재구성 단계 11, 용어 마감): `rg "저장소 추가|에이전트 블록|지휘자|조율자|상위 없는|\+ 워크트리|새 워크트리|\"시스템\"|변경사항|전송|만들고 실행" src` 결과 0줄(주석·식별자 포함). 이 단계에서 바꾼 것: 지도 "+ 워크트리" → "새 에이전트", 캔버스 "+ 프롬프트 블록" → "프롬프트"(툴팁 "에이전트 블록에…" → "선으로 이은 에이전트에게…"), 프롬프트 블록 "전송"/"동시 전송 · N"/"단독 전송" → "보내기"/"보낼 곳 N", "에이전트 블록에 선을 연결하세요" → "에이전트에 선을 이어 주세요", 채팅 입력창 안내 "Enter 전송" → "Enter 보내기", 워커 카드 "↑" → "보내기", 지도 Lead 카드 "워커들을 조율하는 Lead" → "워커에게 일을 나누는 Lead", "Lead 캔버스" 버튼 → "Lead 열기".
- "대기"가 쉬는 상태(IDLE)와 사용자를 기다리는 상태 두 뜻으로 쓰여서, 쉬는 상태는 "쉬는 중", 사용자를 기다리는 것은 "승인 대기"(모음은 "확인할 일")로 나눴어요.
