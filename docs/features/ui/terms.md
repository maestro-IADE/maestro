# 용어

## 요약

같은 것을 서너 가지 말로 부르던 것(프로젝트/저장소, 워크트리/에이전트 블록/워커, 마에스트로/지휘자/조율자, Chat·CLI/채팅·터미널)을 한 이름으로 정한 표예요. 화면 글(버튼, 라벨, 툴팁, 상태, 확인 창)은 아래 "쓰는 말"만 써요. UI 구조 재구성의 각 단계가 자기가 손대는 화면의 글을 이 표대로 고쳐요.

## 동작

**권한 모드**
| id | 이름 (칩 짧은 이름) | 설명 | 받는 에이전트 |
|---|---|---|---|
| `default` | 매번 묻기 (매번 묻기) | 파일 수정과 명령 실행을 모두 승인 카드로 물어봐요 | Claude Code |
| `acceptEdits` | 파일 수정 자동 허용 (수정 자동) | 파일 수정은 묻지 않고 허용해요. 명령 실행 등 다른 도구는 승인 카드로 물어봐요 | Claude Code, Antigravity |
| `auto` | 자동 판단 (자동 판단) | 에이전트가 안전하다고 판단한 작업은 묻지 않아요 | Claude Code, Antigravity |
| `bypassPermissions` | 모두 허용 (주의) (모두 허용) | 묻지 않고 모든 도구를 실행해요. 작업 폴더 밖 파일도 바뀔 수 있어요 | Claude Code, Antigravity |
| `plan` | 계획만 (계획만) | 파일을 바꾸지 않고 계획만 세워요 | Claude Code, Antigravity |

**문구 규칙**(`maestro-web/DESIGN.md` "문구")
- 버튼·라벨·툴팁·한 문장짜리 안내 끝에 마침표·느낌표를 붙이지 않아요. 여러 문장인 문단만 마침표를 써요.
- 버튼은 동작 이름이에요("폐기", "목록에서 제거"). "확인"처럼 무엇을 하는지 말하지 않는 이름은 쓰지 않아요.
- 툴팁은 "이름 (단축키)" 또는 "이름 · 짧은 설명"이에요. 상태 글은 짧게 써요.

## 구현

- 상태 이름: `statusText`(src/status.tsx)가 글리프의 툴팁·이름과 워커 카드의 상태 글자를 같이 줘요.
- 권한 모드: `PERMISSIONS`(src/agents.tsx). 지금은 `acceptEdits`의 설명만 이 표대로예요. 이름 바꾸기, `default`(매번 묻기) 추가, 에이전트마다 받는 모드만 보이게 거르기는 새 에이전트 창을 다시 쓰는 단계에서 함께 해요(Antigravity가 `default`를 받지 않아서, 거르기 없이 넣으면 거짓 선택지가 돼요).
- 확인 창의 제목·버튼 글: 호출하는 곳마다 `ask({ title, confirm })`로 줘요. → [메뉴와 확인 창](menus-and-dialogs.md)

## 제약과 알려진 문제

- 채팅/터미널 쪽 말(`Chat`, `CLI 보기`, `CLI에서`, "CLI 준비 중" 같은 입력창 안내)은 채팅/터미널 전역 보기 단계(12)가 바꿔요. 그 밖의 "쓰지 않는 말"은 단계 11에서 화면 글에서 모두 뺐어요(아래 결정 기록).
- 백엔드(Rust)의 오류 문구는 이 표의 범위 밖이에요.

## 결정 기록

- 2026-11-13 (UI 구조 재구성): 줄 하나를 모두 "워커"로 부르면 독립 에이전트가 누군가의 워커가 되고 문서가 크게 흔들려서, 줄 하나 = 에이전트, 마에스트로 아래 = 워커로 나눴어요.
- 2026-11-13 (UI 구조 재구성 단계 11, 용어 마감): `rg "저장소 추가|에이전트 블록|지휘자|조율자|상위 없는|\+ 워크트리|새 워크트리|\"시스템\"|변경사항|전송|만들고 실행" src` 결과 0줄(주석·식별자 포함). 이 단계에서 바꾼 것: 지도 "+ 워크트리" → "새 에이전트", 캔버스 "+ 프롬프트 블록" → "프롬프트"(툴팁 "에이전트 블록에…" → "선으로 이은 에이전트에게…"), 프롬프트 블록 "전송"/"동시 전송 · N"/"단독 전송" → "보내기"/"보낼 곳 N", "에이전트 블록에 선을 연결하세요" → "에이전트에 선을 이어 주세요", 채팅 입력창 안내 "Enter 전송" → "Enter 보내기", 워커 카드 "↑" → "보내기", 지도 마에스트로 카드 "워커들을 조율하는 마에스트로" → "워커에게 일을 나누는 마에스트로", "마에스트로 캔버스" 버튼 → "마에스트로 열기".
- "대기"가 쉬는 상태(IDLE)와 사용자를 기다리는 상태 두 뜻으로 쓰여서, 쉬는 상태는 "쉬는 중", 사용자를 기다리는 것은 "승인 대기"(모음은 "확인할 일")로 나눴어요.
