# 테마와 모션

## 요약

테마는 6가지예요: 기본, 블루 다크, 그래파이트, 모카, 라이트, 아이보리. 기본 테마는 공식 사이트의 디자인 가이드(`maestro-web/DESIGN.md`)를 그대로 옮긴 테마예요. 글꼴, 모서리, 간격, 버튼, 메뉴, 움직임 같은 테마 밖의 규칙도 이 가이드를 따라서 모든 테마에 똑같이 적용돼요. 색은 `--mae-*` CSS 변수로 정하고 `<html data-theme>`에 따라 바꿔요.

## 동작

**테마**(설정 → 모양)
| id | 이름 | 느낌 |
|---|---|---|
| `default` | 기본 | 기본값. 사이트와 같은 잉크빛 무채색 하나로 면·선·글자를 만들고, 주 버튼은 흰 바탕에 어두운 글자예요. 색은 로고에만 있어요 |
| `dark` | 블루 다크 | 기본 테마보다 조금 더 푸른 잉크빛 무채색, 코발트 강조색 `#3d6fe0`(흰 글자 4.6:1) |
| `graphite` | 그래파이트 | 색기 없는 회색. 프레임과 옆 패널이 캔버스보다 한 단계 밝아요. 주 버튼은 흰 바탕에 어두운 글자 |
| `mocha` | 모카 | 아주 살짝 따뜻한 회색(갈색으로 보이지 않을 만큼), 호박색 강조색 `#e0955a`(어두운 글자) |
| `light` | 라이트 | 푸른 기가 도는 회백색 계열, 코발트 강조색 `#2459d6`(흰 글자 6.0:1). 순백을 쓰지 않아 눈이 덜 부셔요: 가장 밝은 블록이 밝기 약 90%, 캔버스와 패널은 한두 단계 아래 |
| `ivory` | 아이보리 | 종이처럼 따뜻한 회백색 계열, 녹 빛 강조색 `#9a4b1b`(흰 글자 6.2:1). 라이트처럼 순백 없이 밝기를 낮췄어요 |

- **로고 색은 기본 테마에서만:** 기본 테마에서는 움직이는 로고가 모일 때 로고의 다섯 색(`#ffbe6a` `#ff7a9c` `#86ffb5` `#6fd8ff` `#8492ff`)으로 빛나요. 다른 테마에서는 움직일 때도 글자색 한 가지예요.
- **로고 색 빛(기본 테마만):** 주 버튼(`button.primary`)과 사이드바의 큰 줄(문서, 플레이북 같은 `.sb-nav`)에 마우스를 올리면, 포인터 아래에 로고 색의 부드러운 원이 비쳐요. 색은 요소 안에서 포인터의 가로 위치로 정해서, 왼쪽 끝부터 오른쪽 끝까지 다섯 색이 다 지나가요. 사이드바 줄은 22%만 비쳐요.
- 밝은 테마(`light: true`)에서는 캔버스(React Flow)와 터미널, 편집기도 밝은 색 구성을 써요.
- **색 조합 규칙(모든 테마):** 면·선·글자는 무채색(또는 아주 약하게 물든) 단계 하나로 만들어요. 글자는 세 단계(주 / 두 번째 / 흐린)이고, 선은 글자색의 8%(밝은 테마는 10%), 메뉴와 배지 테두리는 14%(밝은 테마 16%)예요. 강조색은 한 가지이고, 그 위에 올리는 글자는 4.5:1 이상이에요. 의미 색(성공 초록, 오류 빨강)은 어두운 테마에서 `#4cc38a` / `#e5484d`, 밝은 테마에서 `#16a34a` / `#dc2626`로 톤을 맞췄어요. 그림자는 무채색이고 밝은 테마에서는 작고 옅어요.
- 저장된 테마가 지금 목록에 없으면(지운 `neon`, `forest` 등) 기본 테마로 돌아가요.
- 이 디자인이 들어간 버전을 처음 켜면 저장된 테마와 이징이 한 번 기본 테마와 "표준"으로 바뀌어요(설정 저장 형식 v1). 그 뒤에 고른 값은 그대로 남아요.

**공통 디자인 규칙**(모든 테마, `DESIGN.md`)
- 글꼴: 영문 Geist, 숫자·코드·메타는 Geist Mono, 한글은 Pretendard. 앱 안에 들어 있어서 인터넷이 없어도 같아요.
- 굵기는 400, 500, 제목에만 600. 700 이상, 대문자 라벨, 넓은 자간, 강조용 이탤릭은 쓰지 않아요. 클래스 없는 `<b>`·`<strong>`도 500이에요(`styles.css`의 전역 규칙): 가변 폰트라 브라우저 기본 `bold`가 진짜 700으로 그려지기 때문이에요. 숫자는 고정폭(`tabular-nums`)이에요.
- 간격은 4px 단위예요. 사이드바와 설정의 줄은 높이 32px.
- 모서리: 버튼·입력 8px, 메뉴·떠 있는 막대·카드 10px, 메뉴 안 항목 6px, 창·대화상자 16px, 배지 4px.
- 배지(PR 상태, 문서, 페르소나 등)는 알약 모양 대신 모서리 4px의 작은 상자예요.
- 메뉴(오른쪽 클릭, `/` 명령): 면 색, 진한 테두리, 안쪽 여백 4px, 항목 8×12px. 열릴 때 4px 올라오며 나타나요.
- 버튼은 누르면 살짝 작아져요(`scale(.98)`). 마우스를 올려도 위치나 크기가 바뀌지 않아요. 키보드로 옮기면 테두리 링이 보여요.
- 강조색은 주 버튼, 선택 상태(열린 탭, 고른 블록·영역·선), 포커스, 스위치, 끌어 놓기·크기 조절 표시, 진행 막대에만 써요. 마에스트로 카드, 병합 카드, 프롬프트 블록, 배지, 폴더 아이콘 같은 나머지는 두 번째 글자색(`--mae-text-2`)이나 진한 선(`--mae-line-strong`)이에요.
- 아이콘은 Lucide 하나(`lucide-react`, `src/icons.tsx`). 선 굵기 1.5, 크기 16px(밀집한 줄 14px, 배지 안 12px), 글자색을 따라요. 마에스트로는 왕관(`Crown`), 페르소나는 사람(`UserRound`), 문서는 `FileText`, 접기 화살표는 `ChevronRight`가 열리면 90° 돌아요. 기호 글자(♛ ♟ ★ ▸ ▾ ↻)는 쓰지 않아요. 닫기·빼기·추가 버튼도 글자 `×`, `+`가 아니라 `X`, `Plus` 아이콘이에요(탭 닫기, 칩 빼기, 선 끊기, 대화상자 닫기, 사이드바 `+`).
- 글자 크기는 11 / 12 / 13 / 14 / 16 / 20px 여섯 단계예요.
- 사이드바 줄은 모두 왼쪽 18px에서 시작해요. 오른쪽 패널의 파일 트리와 변경 목록은 줄 높이 28px, 왼쪽 12px에서 시작해요.
- 문구: 한 문장짜리 안내·상태·설명 줄은 마침표 없이 끝나요. 여러 문장인 문단만 마침표를 써요.

**상태 글리프**(`src/status.tsx`)
에이전트 상태는 색만이 아니라 모양으로도 구분돼요. 16px 칸 가운데에 하나만 그려요.
| 상태 (우선순위 순) | 언제 | 모양 | 색 |
|---|---|---|---|
| 승인 대기 | 도구 승인, 터미널 질문, (마에스트로) 병합 요청이 있음 | 물음표 말풍선 `MessageCircleQuestion` 12px | `--mae-warn` |
| 작업 중 | `RUNNING` | 8px 고리(2px, 위쪽이 비어 있음)가 0.9초에 한 바퀴 | `--mae-status-running` |
| 새 응답 | 안 보는 사이 턴이 끝남(`unread`) | 8px 채운 점 | `--mae-status-unread` |
| 쉬는 중 | `IDLE` | 6px 채운 점 | `--mae-status-idle` |
| 꺼짐 / 에이전트 없음 | `TERMINATED`, 또는 에이전트가 없는 외부 워크트리 | 6px 빈 원(1px 테두리) | `--mae-muted` |
- 쓰는 곳: 사이드바 줄, 가운데 탭, 에이전트 헤더, 캔버스 입력창 머리, 접은 에이전트 블록, 워커 카드, 프로젝트 지도 카드.
- 툴팁과 스크린 리더 이름은 위 상태 이름 그대로예요(용어 → [용어](terms.md)).
- 움직이는 것은 "작업 중" 고리 하나예요. 운영체제의 "동작 줄이기"가 켜져 있으면 고리가 멈추고 테두리가 다 찬 원이 돼요(새 응답의 채운 점과는 여전히 달라요).
- 워커 카드의 상태 글자("작업 중", "쉬는 중", "꺼짐" 등)도 같은 이름을 써요(`statusText`).

**로딩**
- 보통 기다림(버튼 안, "확인 중…" 옆, 에이전트 준비 중 등): 글자 크기의 원형 로딩(`Spinner`, `.spinner`).
- 화면 전체를 불러올 때(프로젝트 목록, 캔버스·스테이지를 여는 중): 큰 로고 로딩(`LogoLoading`, 112px). 기본 테마에서는 로고가 색으로 빛나요.

**캔버스 배경**(설정 → 모양 → 캔버스 배경)
- 점(기본) / 격자 / 십자 / 없음 중에서 골라요. 프로젝트 캔버스와 에이전트 캔버스 모두에 적용되고, 무늬 간격은 블록이 붙는 격자(24px)와 같아요.
- 격자와 십자는 테마의 테두리 색(`--mae-border`)으로 그려서 어느 테마에서도 튀지 않아요.
- **간격**: 촘촘(12px) / 보통(24px, 기본) / 넓게(48px) / 아주 넓게(96px).
- **진하기**: 10–100% 슬라이더(기본 100%). 무늬 색을 그만큼 투명하게 섞어요.
- "없음"이면 간격과 진하기는 꺼져요.

**패널 구분**(설정 → 모양 → 패널 구분)
| 단계 | id | 패널 사이 | 좌우·아래 여백 |
|---|---|---|---|
| 분리(기본) | `cards` | 12px 틈, 패널마다 둥근 테두리 | 있음 |
| 통합 | `lines` | 선 하나, 세 패널이 둥근 상자 하나 | 있음 |
| 와이드 | `full` | 선 하나 | 없음. 창 끝까지 채우고 둥근 모서리도 없어요 |
- 위쪽 막대는 세 단계 모두 같아요.
- 통합/와이드에서 패널을 숨기면 스테이지가 그쪽 테두리(와 모서리)를 이어받아요. 너비 조절 손잡이는 선 위에 걸쳐 있어요.

**모션**(설정 → 모양 → 모션)
- 모션 사용: 끄면 모든 움직임이 0ms가 돼요. 운영체제의 "동작 줄이기"가 켜져 있어도 0ms예요.
- 이징: 표준(기본, `cubic-bezier(.2, 0, 0, 1)`, 사이트와 같음) / 부드럽게 / 탄력 / 일정하게
- 속도: 빠르게 150ms / 보통 240ms(기본) / 느리게 360ms. 색·배경 바뀜은 속도와 상관없이 150ms(`--mae-fast`)예요.
- 미리보기 버튼으로 바로 느낌을 볼 수 있어요.

## 구현

- 목록과 값: `THEMES`, `DEFAULT_THEME`(`"default"`), `logoLit()`, `EASINGS`, `SPEEDS`, `isLightTheme`, `motionMs`(settings.ts). 저장소 `maestro.settings`는 `version: 2`예요. `migrate`가 v0 값을 기본 테마·표준으로 바꾸고, v1에 저장된 옛 id `chrome`을 `default`로 옮겨요.
- 공통 토큰(styles.css `:root`): `--mae-font`, `--mae-mono`, `--mae-r-control`(8), `--mae-r-menu`(10), `--mae-r-item`(6), `--mae-r-badge`(4), `--mae-frame-radius`(16), `--mae-text-2`(두 번째 글자 역할), `--mae-line`/`--mae-line-strong`(글자색 8%/14% 선), `--mae-fast`(150ms). 기본 테마은 `--mae-text-2`, `--mae-line-strong`을 사이트 값으로 직접 정해요.
- 색 토큰: `--mae-frame-bg`, `--mae-panel`, `--mae-panel-2`, `--mae-bg`, `--mae-canvas`, `--mae-node`, `--mae-border`, `--mae-text`, `--mae-muted`, `--mae-accent`, `--mae-on-accent`, `--mae-hover`, `--mae-selected`, `--mae-shadow` 등. `--mae-canvas`와 `--mae-node`는 기본이 `var(--mae-panel)`이에요.
- 글꼴(main.tsx): `@fontsource-variable/geist`, `@fontsource-variable/geist-mono`, `pretendard`(가변, 나눠 받는 subset) CSS를 불러요.
- 로고 색(LogoMotion.tsx): 공용 애니메이션 루프의 `frame()`이 `logoLit()`가 거짓이면 색 사본의 투명도(`mix`)를 0으로 둬요.
- 로고 색 빛(glow.ts): 창 하나에 `pointermove` 리스너 하나. 기본 테마일 때 포인터 아래 `button.primary, .sb-nav`에 `--gx`, `--gy`, `--glow`(`hueAt(x / 너비)`)를 넣고, styles.css의 `::before` 층이 그 자리에 원형 그라데이션을 그려요. 층은 글자 아래(`z-index: -1`, `isolation: isolate`)이고 opacity만 바뀌어요.
- 로딩: `Spinner`는 `<span class="spinner">`(테두리 원, `spin` 0.8초), `LogoLoading`은 112px 로고. 에이전트 준비 화면(`.boot`)의 원은 20px.
- `applySettings`가 `data-theme`, `data-panels`, `--mae-ease`, `--mae-dur`를 `<html>`에 넣어요. 첫 화면을 그리기 전에 한 번 불러서 기본 테마가 깜빡이지 않게 해요.
- 아이콘(icons.tsx): `icon(C, size)`가 Lucide 아이콘을 선 1.5, 기본 크기로 감싸요. 옛 이름(`MaestroIcon`, `PersonaIcon`, `DocIcon`, `DefaultIcon`, `CaretIcon`, `RefreshIcon`, `CloseIcon`)과 함께, 화면 설계에 나오는 아이콘을 Lucide 이름 그대로 내보내요(`Plus`, `X`, `FolderPlus`, `Ellipsis`, `Settings`, `PanelLeft`, `ArrowLeft`, `Bell`, `MessageCircleQuestion`, `SquareTerminal`, `GitBranch`, `GitCompare`, `BookOpen`, `CircleAlert` 등). 기본 16px이고 `size`로 바꿔요. 설정 톱니는 옛 `GearIcon` 대신 `Settings`예요. 설정 탐색 아이콘은 `Settings2`, `Bot`, `FolderGit2`, `Palette`, `Info`예요.
- 상태 글리프(status.tsx): `glyphState({ status, waiting, unread, noAgent })`가 우선순위대로 상태 하나를 고르고, `statusText(state)`가 이름을 줘요. `StatusGlyph`는 `<span class="glyph" data-s="…">`(안에 `<i>` 점·고리, 승인 대기면 Lucide 아이콘)이고 `size`로 칸 크기(기본 16)를 바꿔요. `onToggleRead`를 주면 칸이 버튼이 돼요(행 클릭·더블클릭으로 번지지 않음). 사이드바 세션 행의 상태 레인이 이것을 써요: 읽음/안 읽음을 바꾸고, 승인 대기·작업 중이면 그 에이전트를 열어요. 이때 툴팁 끝에 "· 누르면 읽음"(새 응답) 또는 "· 누르면 안 읽음"(쉬는 중·꺼짐)이 붙어요. → [사이드바](side-panels.md) `AgentGlyph({ w })`는 승인 대기를 `useWaiting(path)`(store.ts)으로 읽어 `StatusGlyph`를 그려요. 고리는 기존 `@keyframes spin`을 0.9초로 써요.

## 제약과 알려진 문제

- 1차 디자인이에요. 화면 구조(어떤 기능이 어디 있는지)는 그대로이고, 색·글꼴·간격·모서리·움직임만 맞췄어요.
- 다른 테마의 강조색(파랑, 주황 등)은 그대로예요. 기본 테마만 강조색이 흰색이에요.

## 결정 기록

- 2026-11-13 (리뷰 수정): 남은 손그림 SVG를 Lucide로 바꿨어요. 에이전트 블록 머리의 "작게 접기"(16px 손그림 → `Minimize2` 14, 머리의 다른 아이콘 버튼과 같은 크기), 접힌 칩의 "창으로 펼치기"(`Maximize2`), 캔버스 아래 입력창 머리의 대화 접기·펼치기(`ChevronDown`/`ChevronUp`), "전체 화면으로 보기"(`Maximize2`), 닫기(`X`), 파일 트리 아이콘(`File`/`Folder`/`FolderOpen`). 단계 11이 워커 카드에서 같은 모양을 바꿨는데 이 자리들이 빠져 있었어요.
- 2026-11-13 (리뷰 수정): `b, strong { font-weight: 500 }`을 전역으로 뒀어요. 승인 카드의 도구 이름, 폐기 창의 "보관"·"버리기", 지도 카드 이름처럼 클래스 없는 `<b>`가 700으로 그려졌어요(Geist·Pretendard 가변 폰트). 600이 아니라 500인 것은 600을 제목에만 쓰기 때문이고, 굵기를 따로 정한 `<b>`(빈 화면 제목 등)는 그대로예요.
- **네온을 빼고 기본 테마를 기본값으로:** 사이트와 앱이 같은 제품으로 보이게 사이트의 디자인 가이드를 그대로 따르는 테마를 기본으로 했어요. 네온의 번짐(glow)과 반투명 유리는 가이드의 "색은 로고에만" 원칙과 맞지 않아요.
- **로딩 두 가지:** 작은 자리마다 로고가 돌면 로고가 흔해지고 산만해요. 일상 로딩은 원, 화면 전체 로딩만 큰 로고로 나눴어요.
- 패널 구분 이름: "프레임"은 바깥 창 프레임과 헷갈리고 "경계"는 뜻이 넓어서 "패널 구분"으로 정했어요.
- 여백 켜기/끄기를 따로 두지 않고 단계에 묶었어요. "분리 + 여백 없음"은 틈은 있는데 가장자리만 붙어 어색해서, 쓸 만한 세 조합만 남겼어요.
- 2026-11-13 (UI 구조 재구성 단계 1): 상태 점(`StatusDot`, 색만 다르고 작업 중·승인 대기면 깜빡이는 8px 점)을 모양이 다른 글리프로 바꾸고 맥박 애니메이션(`@keyframes pulse`)을 지웠어요. 색만으로는 상태를 구분하기 어렵고, 깜빡이는 점이 여럿이면 어느 것이 급한지 알 수 없었어요. 승인 대기는 깜빡임 대신 다른 모양(물음표)과 경고색으로 알려요. 접은 에이전트 블록은 작업 중일 때 로딩 원도 따로 돌렸는데, 고리와 겹쳐 둘이 돌아서 로딩 원을 뺐어요.
- 치수 토큰은 Orca 실측(36/32/28/24, 세션 줄 44+4)을 따랐어요. 글리프를 16px 칸에 그리는 것도 사이드바 줄의 상태 칸과 탭 앞 아이콘 상자를 같은 크기로 맞추기 위해서예요.
