# 테마와 모션

## 요약

테마는 7가지예요: 기본, 다크 블루, 그래파이트, 모카, 라이트, 아이보리, 스톤. 여기에 직접 만든 팔레트(내 팔레트)를 더할 수 있어요. 기본 테마는 공식 사이트의 디자인 가이드(`maestro-web/DESIGN.md`)를 그대로 옮긴 테마예요. 글꼴, 모서리, 간격, 버튼, 메뉴, 움직임 같은 테마 밖의 규칙도 이 가이드를 따라서 모든 테마에 똑같이 적용돼요. 색은 `--mae-*` CSS 변수로 정하고 `<html data-theme>`에 따라 바꿔요.

## 동작

**테마**(설정 → 모양)
| id | 이름 | 느낌 |
|---|---|---|
| `default` | 기본 | 기본값. 보더콜리처럼 검정과 흰색이 또렷한 무채색이에요. 거의 검은 프레임(`#0a0a0a`) 위에 캔버스 `#111112`, 패널 `#18181a`, 블록 `#1f1f22`, 입력 `#26262a`가 눈에 보일 만큼 한 단계씩 밝아지고, 글자는 흰색 `#f5f5f5`예요. 주 버튼은 흰 바탕에 검은 글자예요. 색은 로고에만 있어요 |
| `dark` | 다크 블루 | 기본 테마보다 조금 더 푸른 잉크빛 무채색, 코발트 강조색 `#3d6fe0`(흰 글자 4.6:1) |
| `graphite` | 그래파이트 | 색기 없는 회색. 기본 테마보다 연하고, 층 사이 폭이 넓어요: 가장 진한 캔버스 `#19191b`부터 패널 `#2b2b2f`, 블록 `#323236`, 입력 `#3c3c41`, 선택 `#4d4d53`까지 밝아져요. 프레임과 옆 패널이 캔버스보다 한 단계 밝아요. 주 버튼은 흰 바탕에 어두운 글자 |
| `mocha` | 모카 | 아주 살짝 따뜻한 회색(갈색으로 보이지 않을 만큼), 호박색 강조색 `#e0955a`(어두운 글자) |
| `light` | 라이트 | 푸른 기가 도는 회백색 계열, 코발트 강조색 `#2459d6`(흰 글자 6.0:1). 순백을 쓰지 않아 눈이 덜 부셔요: 가장 밝은 블록이 밝기 약 90%, 캔버스와 패널은 한두 단계 아래 |
| `ivory` | 아이보리 | 종이처럼 따뜻한 회백색 계열, 녹 빛 강조색 `#9a4b1b`(흰 글자 6.2:1). 라이트처럼 순백 없이 밝기를 낮췄어요 |
| `stone` | 스톤 | Astryx(Meta 디자인 시스템, MIT)의 Stone 테마 라이트 모드. 살짝 보랏빛이 도는 회백색(캔버스 `#ececf3`, 패널 `#e7e7ee`, 블록 `#f5f5f9`), 흙빛으로 가라앉힌 상태 색, 아주 진한 잉크 강조색 `#25252a`(흰 글자 15:1). 순백 없이 밝기를 낮췄어요 |

- **로고 색은 기본 테마에서만:** 기본 테마에서는 움직이는 로고가 모일 때 로고의 다섯 색(`#ffbe6a` `#ff7a9c` `#86ffb5` `#6fd8ff` `#8492ff`)으로 빛나요. 다른 테마에서는 움직일 때도 글자색 한 가지예요.
- 마우스를 올렸을 때 로고 색이 비치는 효과는 없어요. 버튼과 줄은 모든 테마에서 배경 한 단계로만 바뀌어요.
**테마 카드**(설정 → 모양 → 테마)
- 테마마다 카드 하나예요. 카드 위쪽은 그 테마의 실제 색으로 그린 작은 창이에요: 프레임, 사이드바(선택된 줄 하나), 격자 캔버스 위 블록 하나(제목·흐린 글자), 강조색 버튼. 아래에 이름이 있어요. 세 칸씩 놓여요.
- 카드에 마우스를 0.2초 올려 두면 앱 전체(설정 창 포함)가 그 테마로 잠깐 바뀌어요. 카드 묶음 밖으로 나가면 저장된 테마로 돌아와요. 누르면 그 테마로 정해져요.
- 고른 카드는 테두리가 두 번째 글자색으로 진해져요.

**내 팔레트**
- 카드 목록 끝 [+ 새 팔레트]를 누르면 아래에 편집 칸이 열려요. 열려 있는 동안 앱 전체가 편집 중인 팔레트로 보여요.
- 정하는 것은 셋이에요(Linear의 사용자 테마와 같은 방식): **바탕**(캔버스 색. 밝기로 다크/라이트가 정해져요), **강조**(주 버튼·선택·포커스), **대비**(0–100, 층 사이 간격. 더블클릭하면 60). 프레임·패널·블록·입력·호버·선택 면과 세 단계 글자색은 여기서 계산해요. 흐린 글자는 가장 밝은(라이트면 가장 어두운) 입력 면에서도 4.5:1이 되게 맞추고, 강조색 위 글자는 흰색과 아주 진한 색 중 더 잘 읽히는 쪽이에요.
- [시작점]에서 기존 테마를 고르면 그 테마의 바탕·강조·대비를 가져와요. 색은 색 고르기 창이나 `#rrggbb`(앞의 `#`는 빼도 돼요)로 넣어요.
- [복사]는 팔레트를 `maestro-palette:…` 한 줄로 클립보드에 넣어요. 다른 컴퓨터에서 그 줄을 붙여 넣고 [불러오기](또는 Enter)를 누르면 같은 색이 돼요. 잘못된 줄이면 아래에 빨간 안내가 나와요.
- [만들기]를 누르면 저장하고 바로 그 팔레트로 바뀌어요. 편집이면 [저장]이에요. [취소]는 아무것도 바꾸지 않아요.
- 만든 팔레트 카드는 ⋯(또는 우클릭)에 편집, 복제, 팔레트 문자열 복사, 지우기…가 있어요. 더블클릭도 편집이에요. 지우기는 확인 창을 거치고, 쓰던 팔레트를 지우면 기본 테마로 돌아가요.
- 내 팔레트에서는 로고가 다른 테마처럼 글자색 한 가지예요.

- 밝은 테마(`light: true`)에서는 캔버스(React Flow)와 터미널, 편집기도 밝은 색 구성을 써요.
- **색 조합 규칙(모든 테마):** 면·선·글자는 무채색(또는 아주 약하게 물든) 단계 하나로 만들어요. 글자는 세 단계(주 / 두 번째 / 흐린)이고, 선은 글자색의 8%(밝은 테마는 10%), 메뉴와 배지 테두리는 14%(밝은 테마 16%)예요. 강조색은 한 가지이고, 그 위에 올리는 글자는 4.5:1 이상이에요. 의미 색(성공 초록, 오류 빨강)은 어두운 테마에서 `#4cc38a` / `#e5484d`, 밝은 테마에서 `#16a34a` / `#dc2626`로 톤을 맞췄어요. 그림자는 무채색이고 밝은 테마에서는 작고 옅어요.
- 저장된 테마가 지금 목록에 없으면(지운 `neon`, `forest` 등) 기본 테마로 돌아가요.
- 이 디자인이 들어간 버전을 처음 켜면 저장된 테마와 이징이 한 번 기본 테마와 "표준"으로 바뀌어요(설정 저장 형식 v1). 그 뒤에 고른 값은 그대로 남아요.

**공통 디자인 규칙**(모든 테마, `DESIGN.md`)
- 글꼴: 영문 Geist, 숫자·코드·메타는 Geist Mono, 한글은 Pretendard. 앱 안에 들어 있어서 인터넷이 없어도 같아요.
- 굵기는 400, 500, 제목에만 600. 700 이상, 대문자 라벨, 넓은 자간, 강조용 이탤릭은 쓰지 않아요. 클래스 없는 `<b>`·`<strong>`도 500이에요(`styles.css`의 전역 규칙): 가변 폰트라 브라우저 기본 `bold`가 진짜 700으로 그려지기 때문이에요. 숫자는 고정폭(`tabular-nums`)이에요.
- 간격은 4px 단위예요. 사이드바와 설정의 줄은 높이 32px.
- 모서리: 버튼·입력 8px, 메뉴·떠 있는 막대·카드 10px, 메뉴 안 항목 6px, 창·대화상자 16px, 배지 4px.
- 배지(PR 상태, 문서, 페르소나 등)는 알약 모양 대신 모서리 4px의 작은 상자예요.
- 메뉴(오른쪽 클릭, `/` 명령): 면 색, 진한 테두리, 안쪽 여백 4px, 항목 8×12px. 열릴 때 4px 올라오며 나타나요.
- 버튼은 누르면 살짝 작아져요(`scale(.98)`). 마우스를 올려도 위치나 크기가 바뀌지 않아요. 키보드로 옮기면 테두리 링이 보여요.
- 강조색은 주 버튼, 선택 상태(열린 탭, 고른 블록·영역·선), 포커스, 스위치, 끌어 놓기·크기 조절 표시, 진행 막대에만 써요. Lead 카드, 병합 카드, 프롬프트 블록, 배지, 폴더 아이콘 같은 나머지는 두 번째 글자색(`--mae-text-2`)이나 진한 선(`--mae-line-strong`)이에요.
- 아이콘은 Lucide 하나(`lucide-react`, `src/icons.tsx`). 선 굵기 1.5, 크기 16px(밀집한 줄 14px, 배지 안 12px), 글자색을 따라요. 페르소나는 사람(`UserRound`), 문서는 `FileText`, 접기 화살표는 `ChevronRight`가 열리면 90° 돌아요. 기호 글자(♛ ♟ ★ ▸ ▾ ↻)는 쓰지 않아요. 닫기·빼기·추가 버튼도 글자 `×`, `+`가 아니라 `X`, `Plus` 아이콘이에요(탭 닫기, 칩 빼기, 선 끊기, 대화상자 닫기, 사이드바 `+`).
- 글자 크기는 11 / 12 / 13 / 14 / 16 / 20px 여섯 단계예요.
- 사이드바 줄은 모두 왼쪽 18px에서 시작해요. 오른쪽 패널의 파일 트리와 변경 목록은 줄 높이 28px, 왼쪽 12px에서 시작해요.
- 문구: 한 문장짜리 안내·상태·설명 줄은 마침표 없이 끝나요. 여러 문장인 문단만 마침표를 써요.

**상태 글리프**(`src/status.tsx`)
에이전트 상태는 색만이 아니라 모양으로도 구분돼요. 16px 칸 가운데에 하나만 그려요.
| 상태 (우선순위 순) | 언제 | 모양 | 색 |
|---|---|---|---|
| 승인 대기 | 도구 승인, 터미널 질문, (Lead) 병합 요청이 있음 | 물음표 말풍선 `MessageCircleQuestion` 12px | `--mae-warn` |
| 작업 중 | `RUNNING` | 8px 고리(2px, 위쪽이 비어 있음)가 0.9초에 한 바퀴 | `--mae-status-running` |
| 새 응답 | 안 보는 사이 턴이 끝남(`unread`) | 8px 채운 점 | `--mae-status-unread` |
| 쉬는 중 | `IDLE` | 6px 채운 점 | `--mae-status-idle` |
| 꺼짐 / 에이전트 없음 | `TERMINATED`, 또는 에이전트가 없는 외부 워크트리 | 6px 빈 원(1px 테두리) | `--mae-muted` |
- 쓰는 곳: 사이드바 줄, 가운데 탭, 에이전트 헤더, 캔버스 입력창 머리, 접은 에이전트 블록, 워커 카드, 프로젝트 지도 카드.
- 툴팁과 스크린 리더 이름은 위 상태 이름 그대로예요(용어 → [용어](terms.md)).
- 움직이는 것은 "작업 중" 고리 하나예요. 운영체제의 "동작 줄이기"가 켜져 있으면 고리가 멈추고 테두리가 다 찬 원이 돼요(새 응답의 채운 점과는 여전히 달라요).
- 워커 카드의 상태 글자("작업 중", "쉬는 중", "꺼짐" 등)도 같은 이름을 써요(`statusText`).

**로딩**
- 보통 기다림(버튼 안, "확인 중…" 옆, 에이전트 준비 중 등): 글자 크기의 원형 로딩(`Spinner`, `.spinner`).
- 화면 전체를 불러올 때(프로젝트 목록, 캔버스·스테이지를 여는 중): 큰 로고 로딩(`LogoLoading`, 112px). 기본 테마에서는 로고가 색으로 빛나요.

**캔버스 배경**(설정 → 모양 → 캔버스 배경)
- 점 / 격자(기본) / 십자 / 없음 중에서 골라요. 이미 고른 값이 있으면 그대로예요. 프로젝트 캔버스와 에이전트 캔버스 모두에 적용되고, 무늬 간격은 블록이 붙는 격자(24px)와 같아요.
- 격자와 십자는 무늬 전용 색(`--mae-grid`, 글자색 5%, 밝은 테마 6%)으로 카드 테두리보다 한 단계 옅게 그려서 블록 경계가 묻히지 않아요. 점은 작아서 조금 진하게(`--mae-grid-dot`, 18% / 22%) 그려요.
- 축소하면 화면에서 무늬 간격이 12px보다 좁아지지 않게 간격을 두 배씩 넓혀요. React Flow는 간격만 줄이고 선 굵기는 그대로라, 그대로 두면 바탕이 칠해진 것처럼 촘촘해졌어요.
- **간격**: 촘촘(12px) / 보통(24px, 기본) / 넓게(48px) / 아주 넓게(96px).
- **진하기**: 10–100% 슬라이더(기본 100%). 무늬 색을 그만큼 투명하게 섞어요.
- "없음"이면 간격과 진하기는 꺼져요.

**패널 구분**(설정 → 모양 → 패널 구분)
| 단계 | id | 패널 사이 | 좌우·아래 여백 |
|---|---|---|---|
| 분리(기본) | `cards` | 12px 틈, 패널마다 둥근 테두리 | 있음 |
| 통합 | `lines` | 선 하나, 세 패널이 둥근 상자 하나 | 있음 |
| 와이드 | `full` | 선 하나 | 없음. 창 끝까지 채우고 둥근 모서리도 없어요 |
- 위쪽 막대는 세 단계 모두 같아요.
- 통합/와이드에서 패널을 숨기면 스테이지가 그쪽 테두리(와 모서리)를 이어받아요. 너비 조절 손잡이는 선 위에 걸쳐 있어요.

**모션**(설정 → 모양 → 모션)
- 모션 사용: 끄면 모든 움직임이 0ms가 돼요. 운영체제의 "동작 줄이기"가 켜져 있어도 0ms예요.
- 이징: 표준(기본, `cubic-bezier(.2, 0, 0, 1)`, 사이트와 같음) / 부드럽게 / 탄력 / 일정하게
- 속도: 빠르게 150ms / 보통 240ms(기본) / 느리게 360ms.
- 색 바뀜(마우스 올리기, 포커스, 선택, 테마 바꾸기)은 속도·이징 설정과 상관없이 200ms(`--mae-color`), 시작이 튀지 않는 곡선 `cubic-bezier(.4, 0, .2, 1)`(`--mae-color-ease`)로 부드럽게 바뀌어요. 글자색, 바탕, 선, 아이콘이 모두 같아요. 메뉴 항목의 강조만 키보드로 빠르게 옮겨 다니도록 바로 바뀌어요.
- 미리보기 버튼으로 바로 느낌을 볼 수 있어요.

- 내 팔레트(palette.ts, 순수 모듈, `scripts/palette-check.ts`로 검사): `derivePalette({ base, accent, contrast })`가 OKLCH에서 바탕의 밝기 `L0`부터 `k = 0.012 + 대비/100 × 0.04`씩 층을 올리거나(다크) 내려요(라이트). 면의 채도는 바탕의 것을 0.03까지만 남겨 거의 무채색이에요. 흐린 글자는 입력 면(`--mae-panel-2`)과 4.6:1이 될 때까지 밝기를 옮겨 정하고, 두 번째 글자는 글자와 흐린 글자의 가운데예요. `PALETTE_KEYS` 15개를 내놓아요. `encodePalette`/`decodePalette`는 `maestro-palette:` + JSON의 base64(한글 이름도 그대로)이고, 색이 틀리면 null이에요. `BUILTIN_SEEDS`는 기본 테마들의 시작점이에요.
- 적용(settings.ts): `applyTheme`이 내 팔레트면 `data-theme`을 `custom`/`custom-light`로 두고 `PALETTE_KEYS`를 `<html>` 인라인 스타일로 넣어요. 다른 테마로 바꾸면 그 인라인 값을 지워요. `previewTheme(theme | null)`은 저장하지 않고 잠깐 보여 줘요(카드 위 마우스, 편집 중). `isLightTheme`은 팔레트의 밝기를 보고, 캔버스(React Flow)는 `useSettings((s) => isLightTheme(s.theme))`로 다크/라이트를 따라가요.
- 로고 색(LogoMotion.tsx): 공용 애니메이션 루프의 `frame()`이 `logoLit()`가 거짓이면 색 사본의 투명도(`mix`)를 0으로 둬요.
- 로딩: `Spinner`는 `<span class="spinner">`(테두리 원, `spin` 0.8초), `LogoLoading`은 112px 로고. 에이전트 준비 화면(`.boot`)의 원은 20px.
- `applySettings`가 `data-theme`, `data-panels`, `--mae-ease`, `--mae-dur`를 `<html>`에 넣어요. 첫 화면을 그리기 전에 한 번 불러서 기본 테마가 깜빡이지 않게 해요.
- 아이콘(icons.tsx): `icon(C, size)`가 Lucide 아이콘을 선 1.5, 기본 크기로 감싸요. 옛 이름(`PersonaIcon`, `DocIcon`, `DefaultIcon`, `CaretIcon`, `RefreshIcon`, `CloseIcon`)과 함께, 화면 설계에 나오는 아이콘을 Lucide 이름 그대로 내보내요(`Plus`, `X`, `FolderPlus`, `Ellipsis`, `Settings`, `PanelLeft`, `ArrowLeft`, `Bell`, `MessageCircleQuestion`, `SquareTerminal`, `GitBranch`, `GitCompare`, `BookOpen`, `CircleAlert` 등). 기본 16px이고 `size`로 바꿔요. 설정 톱니는 옛 `GearIcon` 대신 `Settings`예요. 설정 탐색 아이콘은 `Settings2`, `Bot`, `FolderGit2`, `Palette`, `Info`예요.
- 상태 글리프(status.tsx): `glyphState({ status, waiting, unread, noAgent })`가 우선순위대로 상태 하나를 고르고, `statusText(state)`가 이름을 줘요. `StatusGlyph`는 `<span class="glyph" data-s="…">`(안에 `<i>` 점·고리, 승인 대기면 Lucide 아이콘)이고 `size`로 칸 크기(기본 16)를 바꿔요. `onToggleRead`를 주면 칸이 버튼이 돼요(행 클릭·더블클릭으로 번지지 않음). 사이드바 세션 행의 상태 레인이 이것을 써요: 읽음/안 읽음을 바꾸고, 승인 대기·작업 중이면 그 에이전트를 열어요. 이때 툴팁 끝에 "· 누르면 읽음"(새 응답) 또는 "· 누르면 안 읽음"(쉬는 중·꺼짐)이 붙어요. → [사이드바](side-panels.md) `AgentGlyph({ w })`는 승인 대기를 `useWaiting(path)`(store.ts)으로 읽어 `StatusGlyph`를 그려요. 고리는 기존 `@keyframes spin`을 0.9초로 써요.
