# 사이드바와 양쪽 패널

## 요약

왼쪽 사이드바(프로젝트·에이전트)와 오른쪽 패널(파일·변경)은 위쪽 막대 버튼으로 숨기거나 보일 수 있고, 가운데 화면과의 경계를 끌어 너비를 바꿀 수 있어요. 보임 상태와 너비는 저장돼요. 사이드바는 머리(32px) / 프로젝트 목록 / 바닥(문서·플레이북) 세 부분이에요. 프로젝트 머리(28px)를 누르면 그 프로젝트 지도가 바로 열리고, 쉐브론으로 그 프로젝트만 접어요. 나머지 동작은 프로젝트 메뉴(⋯, 우클릭)에 있어요.

## 동작

**숨기기**
- 위쪽 막대의 패널 아이콘으로 숨기고 보여요. 접히는 움직임은 모션 설정을 따라요.
- 숨긴 패널의 내용은 그대로 살아 있어서, 다시 열면 펼친 폴더 같은 상태가 남아 있어요.

**너비 조절**
- 경계(10px 틈)에 마우스를 올리면 커서가 바뀌고 얇은 강조색 선이 보여요.
- 끌어서 바꿔요. 왼쪽은 220~480px(기본 280), 오른쪽은 220~560px(기본 320)이에요.
- 저장된 너비가 범위 밖이면(예: 예전 범위로 저장한 180px) 읽을 때 범위 안으로 잘라요.
- 경계를 더블클릭하면 기본 너비로 돌아가요.
- 패널을 숨기면 그쪽 손잡이도 사라져요.

**사이드바 머리(32px)**
- 아래 경계선이 탭 막대 아래 선과 한 높이로 이어져요.
- 왼쪽 "프로젝트"(12px, 500). 오른쪽 24×24 버튼 둘:
  - `ChevronsDownUp` "모두 접기" / `ChevronsUpDown` "모두 펴기": 모든 프로젝트가 접혀 있으면 펴기, 하나라도 펼쳐져 있으면 접기예요.
  - `FolderPlus` "프로젝트 추가": 폴더를 골라 추가해요. 고른 폴더가 Git 저장소가 아니면 확인 창("Git 저장소가 아니에요", [Git 저장소로 만들고 추가])으로 묻고, 저장소지만 커밋이 없으면 첫 커밋만 만들지 물어요("아직 커밋이 없어요", [첫 커밋 만들고 추가]). 워커 워크트리는 커밋에서 갈라져 나와야 해서예요. 승낙하면 `init_repo` 후 추가해요. 추가한 프로젝트는 펼쳐진 채 보이고 지도가 열려요. → [메뉴와 확인 창](menus-and-dialogs.md)

**프로젝트 머리(28px)**
- 왼쪽부터 쉐브론 상자(16px, 펴져 있으면 90° 돌아감) → 이름(13px, 600, 넘치면 말줄임). 지금 포커스된 묶음의 프로젝트면 이름이 가장 진한 글자색이에요. 마우스를 올리면 "이름 · 기본 브랜치 · 경로" 툴팁이 떠요.
- **쉐브론**을 누르면 그 프로젝트만 접거나 펴요. 접힌 프로젝트는 앱을 다시 켜도 접혀 있어요.
- **나머지 자리**를 누르면 그 프로젝트 지도가 바로 열려요(기다림 없음). 이미 어떤 묶음에 보이고 있으면 그 묶음으로 가요. 키보드로는 머리에 포커스를 두고 Enter나 Space.
- 접혀 있을 때만 오른쪽에 요약(11px)이 보여요: 기다리는 일이 있으면 "승인 대기 N"(경고색), 없고 작업 중인 에이전트가 있으면 "작업 중 N"(흐린 글자), 둘 다 없으면 비어 있어요. N은 그 프로젝트 에이전트들의 도구 승인·터미널 질문·병합 요청 개수예요.
- 마우스를 올리거나 머리 안에 포커스가 있거나 메뉴가 열려 있으면 오른쪽 끝에 20×20 버튼 둘이 요약을 덮어요(글 폭은 그대로): `Plus` "새 에이전트", `Ellipsis` "프로젝트 메뉴".
- **프로젝트 메뉴**(⋯ 또는 머리 우클릭, 메뉴 키·Shift+F10):
  1. 새 에이전트
  2. 마에스트로 만들기(마에스트로가 있으면 "마에스트로 열기": 마에스트로를 고정 탭으로 열어요)
  3. 분할로 열기: 지금 묶음 오른쪽에 분할로 열어요. 이미 보이고 있으면 그 묶음으로 가요. 예전 "프로젝트 더블클릭"이 여기로 옮겨졌어요. → [워크스페이스](split-and-windows.md)
  4. 프로젝트 설정…: 설정 창의 프로젝트 섹션(병합 방식)을 열어요.
  5. 폴더 경로 복사
  6. ─
  7. 목록에서 제거…(빨강): 확인 창("'<이름>'을 목록에서 제거할까요?", [목록에서 제거])을 거쳐 사이드바에서만 빼요. 디스크의 파일과 워크트리는 그대로예요.
- "새 에이전트"와 "마에스트로 만들기"는 그 프로젝트 지도를 연 뒤 새 에이전트 창을 띄워요.
- 프로젝트 사이는 8px 떨어져 있어요.

**에이전트 줄**(펼친 프로젝트 아래)
- 에이전트가 계층 순서로 나와요. 마에스트로가 먼저, 워커는 들여쓰기돼요. → [워커 계층](../orchestration/worker-hierarchy.md)
- 줄에 보이는 것:
  - 상태 글리프와 에이전트 로고 → [테마와 모션](themes-and-motion.md)
  - 마에스트로면 왕관과 굵은 이름(배경 강조는 없어요. 선택처럼 보여서 뺐어요)
  - 상태 글자는 "승인 대기"만 보여요. 작업 중·새 응답·쉬는 중·꺼짐은 상태 글리프의 모양으로 보여요.
- 클릭은 미리보기 탭, 더블클릭은 고정 탭으로 열어요.
- 에이전트가 하나도 없는 프로젝트에는 28px 줄 `Plus` "새 에이전트"가 하나 있어요. 누르면 새 에이전트 창이 떠요.

**바닥**
- 위 경계선 아래 28px 줄 둘: `FileText` "문서", `BookOpen` "플레이북". 누르면 포커스된 묶음이 다른 프로젝트로 바뀌듯 [시스템](system-tab.md)으로 바뀌고 그 보드를 보여 줘요. 지금 보이는 보드의 줄이 강조돼요. 기본 테마에서는 마우스 아래에 로고 색 패치가 비쳐요.
- 프로젝트 목록이 길어도 바닥은 늘 보여요(목록만 스크롤).

**빈 상태**(프로젝트 없음)
- 사이드바: "프로젝트 폴더를 추가하면 에이전트마다 따로 된 작업 폴더에서 일해요" + [프로젝트 추가] 버튼.
- 가운데 화면: 같은 문장, 워크트리가 만들어지는 곳 안내 한 줄, 주 버튼 [프로젝트 추가].

- 설정 버튼은 사이드바에 없어요. 위쪽 막대의 톱니(Ctrl+,)로 열어요. → [창 프레임](window-frame.md)

## 구현

- 보임: `usePanelPref("maestro.showLeft" | "maestro.showRight")`, `.app[data-hide-left|right]`
- 너비: `usePanelWidth(key, def, min, max)`(App.tsx). 왼쪽 `("maestro.leftWidth", 280, 220, 480)`, 오른쪽 `("maestro.rightWidth", 320, 220, 560)`. 저장값을 읽을 때와 바꿀 때 모두 `clamp`해요.
  - `.app`의 인라인 스타일로 `--mae-sidebar-w`, `--mae-right-w`를 바꿔요.
- 손잡이: `Resizer`(App.tsx)
  - pointer capture로 끌기를 처리해요.
  - 끄는 동안 `.app[data-resizing]`이 켜져서 다음이 바뀌어요.
    - 너비 애니메이션을 꺼서 패널이 늦게 따라오지 않게 해요.
    - 스테이지의 포인터를 막아서 캔버스나 터미널이 움직임을 가로채지 않게 해요.
- 손잡이는 shell 틈(10px)에 놓인 flex 항목이에요. 음수 margin으로 늘어나는 틈을 상쇄해요.
- 사이드바(Sidebar.tsx)
  - `Sidebar`: 머리 `.sb-head`(높이 `var(--h-bar)`, 아래 경계), 목록 `.sb-body`(스크롤, 안쪽 4 8 8), 바닥 `.sb-foot`(위 경계, `.sb-nav` 줄 둘). 단축키 가드는 `.sb-body`를 사이드바 목록으로 봐요(`shortcuts.ts`).
  - `ProjectGroup`: 프로젝트 하나. 머리 `.repo-head`(높이 `var(--h-head)`, `role="button"`), 쉐브론 `.repo-caret`, 요약 `.repo-sum[data-warn]`, 덮개 `.repo-actions`(`position: absolute; right: 4px`, 머리와 같은 `--mae-hover` 면, `opacity` 0→1). 덮개는 `:hover`, `:focus-within`, `[data-menu-open]`(메뉴가 열린 동안 `openMenu`가 머리에 붙임)일 때 보여요.
  - 머리 클릭은 `setActive(root)`를 바로 불러요. 쉐브론과 덮개 버튼은 `stopPropagation`해요.
  - 접기: `useFolded(repos, ready)`. localStorage `maestro.foldedProjects` = 접힌 프로젝트 root의 JSON 배열. 저장할 때 목록에 없는 root는 빼요(목록에서 제거하면 그 root도 빠져요).
  - 옛 키 이행: 목록을 읽은 뒤 `maestro.projectsShut`이 있으면 지워요. 그 값이 `"1"`이고 `maestro.foldedProjects`가 아직 없으면 그때 있던 모든 프로젝트를 접힌 것으로 저장해요.
  - 접힌 요약: `useProjectSummary(root)`가 그 프로젝트 에이전트 경로(`samePath`)에 걸린 `approvals` + `tuiWaits` + `merges`(마에스트로 경로) 개수와 `RUNNING` 에이전트 수를 세요. 지금 `useWaiting`과 같은 규칙이에요(UI 구조 재구성 단계 5에서 확인할 일 모델로 바꿔요).
  - 프로젝트 메뉴: `openMenu(at, items, { owner: 머리 })`(ui/Menu.tsx). 우클릭은 포인터 자리, 메뉴 키처럼 좌표가 없으면 머리 아래, ⋯는 버튼 아래에 떠요.
  - `addProject()`: 폴더 고르기 → `repo_state` → (확인 창) `init_repo` → `addRepo`. 사이드바 머리, 사이드바 빈 상태, 가운데 빈 화면(App.tsx)이 같이 써요.
  - `newAgent(root, mode)`: `setActive(root)` 뒤 스토어 `openNewAgent({ root, mode })`.
- 새 에이전트 창 상태는 스토어에 있어요: `newAgent: { root, mode: "agent" | "worker" | "maestro", parentPath? } | null`, `openNewAgent`, `closeNewAgent`. 창마다 `WindowLayers`(Workspace.tsx)의 `NewAgentHost`가 그려요. 여는 곳(사이드바, 지도, 캔버스 `+ 워커`와 선 끌기)은 모두 이 함수를 불러요.
- 사이드바 상태 글자: `STATUS_LABEL`(Sidebar.tsx). 상태 글자는 일부러 비워 뒀어요(승인 대기만 따로 표시).

## 제약과 알려진 문제

- 창이 아주 좁을 때 양쪽을 최대로 늘리면 가운데가 매우 좁아질 수 있어요. 창 크기에 맞춘 제한은 없어요.
- 에이전트 줄(세션 줄)은 아직 예전 모양(한 줄, 32px)이에요. UI 구조 재구성 단계 4에서 44px 두 줄과 줄 메뉴로 바꿔요.
- 접힌 요약의 "승인 대기 N"은 기다리는 일의 개수예요(에이전트 수가 아니에요). 한 에이전트에 승인이 둘이면 2예요.
- 프로젝트 머리는 버튼 역할(`role="button"`) 안에 버튼(쉐브론, 덮개)이 들어 있어요. 화면 읽기 프로그램에서는 머리와 버튼이 따로 읽혀요.

## 결정 기록

- 2026-11-13 (UI 구조 재구성 단계 2): 사이드바 아래 설정 행을 없앴어요. 사이드바를 숨기면 닿지 않던 자리라, 설정을 늘 보이는 위쪽 막대로 옮겼어요.
- 2026-11-13 (UI 구조 재구성 단계 3): 사이드바를 머리 / 목록 / 바닥으로 나눴어요. 머리를 탭 막대와 같은 32px로 맞춰 세 패널 위 선이 일직선이 돼요. 문서·플레이북은 매일 쓰는 프로젝트 목록 위를 차지하지 않게 바닥으로 내렸어요.
- 같은 날: 프로젝트 머리 클릭을 220ms 기다리던 것을 없앴어요. 기다림은 더블클릭(분할)과 구분하려던 것이라, 분할을 프로젝트 메뉴 "분할로 열기"로 옮기고 클릭은 바로 지도를 열어요. 더블클릭은 툴팁에만 적혀 있어 찾기 어려웠어요.
- 같은 날: 목록 전체를 접던 "프로젝트" 머리줄 대신 프로젝트마다 쉐브론으로 접어요. 접힌 프로젝트도 "승인 대기 N"으로 신호를 남겨요. 예전처럼 한 번에 접고 싶으면 머리의 "모두 접기"를 써요.
- 같은 날: 생성 `+`와 파괴 `×`가 머리에 나란히 있던 것을 없앴어요. "목록에서 제거"는 프로젝트 메뉴 끝의 빨간 항목이고 확인 창을 거쳐요(누르는 횟수는 2 → 3, 일부러 늘렸어요).
- 같은 날: 사이드바 기본 폭을 260 → 280, 최소를 180 → 220으로 올렸어요. 에이전트 이름이 넉넉히 보이게 하려는 단계 4의 두 줄 행 기준 폭이에요. 오른쪽 패널 기본은 300 → 320이에요.
