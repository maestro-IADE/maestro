# 흐름

## 요약

에이전트가 캔버스에 설명 한 줄(`--say`)과 함께 차례로 보여 준 것을 "흐름"으로 저장해 둬요. 캔버스 오른쪽 위의 "흐름" 버튼으로 목록을 펼쳐 보고, 다시 볼 수 있어요. 에이전트도 `maestro canvas`로 흐름을 읽을 수 있어요.

## 동작

- **저장**: 설명 한 줄이 붙은 걸음이 캔버스에 나타날 때마다 그 걸음이 저장돼요: 그 한 줄, 그리고 그때 보여 준 것(새로 놓인 것, 가리킨 것, 바뀐 것). 설명이 없는 걸음은 저장하지 않아요.
- **한 흐름**: 3분 안에 이어서 나온 걸음들은 한 흐름이에요. 그보다 오래 조용하다가 나온 걸음은 새 흐름을 시작해요.
- **제목**: 첫 걸음의 한 줄이 제목이 돼요(40자까지). 목록에서 제목을 눌러 고칠 수 있어요(Enter 또는 다른 곳을 누르면 저장, 비우면 첫 줄로 돌아가요).
- **요약**: 제목 옆에 걸음 수가 나와요("4걸음"). 흐름에 요약이 적혀 있으면(`summary`) 걸음 수 대신 그것이 나와요. 지금은 요약을 적는 화면이나 명령이 없어요.
- **목록**: 흐름이 하나라도 있으면 캔버스 오른쪽 위에 "흐름 N" 버튼이 생겨요. 누르면 목록이 펼쳐지고(가장 최근 것이 위), 다시 누르면 접혀요.
- **다시 보기**(▶): 그 흐름의 걸음이 처음부터 차례로 다시 나와요. 걸음마다 설명 한 줄이 뜨고 화면이 그때 보여 준 것으로 가요. 넘어가는 방식은 지금 설정(시각화 허용: 자동 / 눌러서)을 따라요. 그사이 지워진 것은 건너뛰어요(설명은 그대로 떠요).
- **지우기**(×): 그 흐름을 목록에서 지워요. 캔버스의 그림은 그대로예요.
- 흐름은 캔버스 파일에 함께 저장돼요. 캔버스마다 20개까지이고, 넘치면 가장 오래된 것이 빠져요.
- **에이전트가 읽기**: `maestro canvas`의 답에 `flows`가 나와요(흐름이 있을 때만): 흐름마다 `title`과 `steps`(걸음마다 `say`와 `shows`: 보여 준 것의 이름). 에이전트는 전에 무엇을 어떤 순서로 설명했는지 알 수 있어요.

## 구현

- `canvasFlows.ts`(순수 함수): `Flow { id, title, summary?, at, end, steps }`, `FlowStep { say, ids, names }`. `record(flows, step, now, id)`(마지막 흐름의 `end`에서 `FLOW_GAP` 3분 안이면 거기에 붙이고, 아니면 새 흐름), `retitle`, `without`, `flowsFrom(saved)`(파일에서 읽은 것을 거르기), `FLOWS_MAX` 20.
- Canvas.tsx: `flows` 상태. 불러올 때 `flowsFrom(state.flows)`, 저장할 때 `state.flows`. `present()`가 설명이 있는 걸음을 `record`로 넣어요(보여 준 것: 가리킨 이름 → 새로 놓인 노드 → 바뀐 노드 순으로 고른 id와 그 제목). `replay(flow)`는 걸음마다 `again` 표시가 붙은 장면을 대기열에 넣고 `pump()`를 불러요: 그런 장면은 놓는 것이 없고, 다시 저장되지 않고, 채팅 카드로 기다리지 않아요. 목록은 `Panel position="top-right"`(`.canvas-flows`).
- `canvas.rs` `read`: 저장된 `flows`를 `{ title, steps: [{ say, shows }] }`로 답에 넣어요(있을 때만).
- 시험: `scripts/focus-check.ts`(한 흐름으로 묶기, 새 흐름, 제목, 지우기, 최대 개수, 파일에서 읽기).

## 제약과 알려진 문제

- 화면에서 확인하지 않았어요(2026-11-19, 타입 검사와 규칙 시험만).
- 캔버스가 열려 있을 때 나타난 걸음만 저장돼요.
- 다시 보기는 그때 본 화면을 그대로 되살리지 않아요: 지금 캔버스에서 그 블록들이 있는 곳으로 화면을 옮길 뿐이에요. 영역의 단계·상태 넘기기나 배치 정리는 다시 하지 않아요.
- 요약은 저장 형식에만 있어요. 적는 방법(화면, 에이전트 명령)과 에이전트가 흐름을 고치는 명령은 아직 없어요.
- 되돌리기(Ctrl+Z)는 흐름 목록을 되돌리지 않아요.

## 결정 기록

- 2026-11-19 (사용자: "LLM이 텍스트 가이드와 함께 화면 흐름 보여 줬던 거를 저장해 두자. 이걸 참조시키면 편집할 수도 있고. 우측 상단에 토글로 리스트 펼쳐 볼 수 있고 다시 재생도 할 수 있으며 간단한 요약과 제목이 있을 수도 있는 거야"): 흐름을 넣었어요. 이번에 만든 것은 저장, 목록, 다시 보기, 제목 고치기, 에이전트가 읽기까지예요. "3분 안이면 한 흐름"으로 묶는 기준, 제목을 첫 줄로 하는 것, 요약 자리에 걸음 수를 보이는 것은 제 판단이에요. 에이전트가 흐름을 고치는 것과 요약을 적는 것은 다음 단계로 남겼어요.
